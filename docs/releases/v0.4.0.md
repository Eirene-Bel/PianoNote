# PianoNote v0.4.0

## 日本語

- Android・紹介ページ・サンプル体験を9言語に対応：日本語、英語、中国語（簡体字／繁体字）、韓国語、スペイン語、フランス語、ドイツ語、ポルトガル語。
- 端末・ブラウザーの言語に合わせた自動表示と手動切り替えに対応。
- READMEも9言語に対応。
- 英語・ドイツ語で「FA」などの連続入力を正しく採点。
- スマホ画面でもサンプルの言語を切り替え可能。

Android 16以降。本リリースのAPKは既存版と同じ署名鍵で作成しています。練習記録・JSONバックアップの形式は変更していません。Android 16エミュレーターでv0.3.3からの上書き更新と記録保持、9言語の起動・基本画面の表示を確認しました。実機での更新確認は未実施です。

## English

- Nine offline languages for Android, the website, and the demo: Japanese, English, Simplified/Traditional Chinese, Korean, Spanish, French, German, and Portuguese.
- Automatic device/browser language detection and manual selection.
- README documentation in all nine languages.
- Correct scoring of adjacent letter names such as FA in English and German.
- Language selection available on mobile demo screens.

Requires Android 16 or later. This APK is signed with the existing release key. Practice records and the JSON backup format are unchanged. An update from v0.3.3, record retention, and launch/basic-screen labels in all nine languages were verified on an Android 16 emulator. Upgrade testing on a physical device has not been performed.
